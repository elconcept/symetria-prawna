# Opcjonalna konsultacja lokalnego MCP w ChatGPT
Jeżeli lokalny executor udostępnia MCP, sprawdź draft narzędziami flag_asymmetry i rzecznik_obywatela, następnie popraw, wykonaj audyt A-K i prześlij do gate_response audyt oraz receipt związane SHA256 z dokładnym draftem. Serwer Rzecznika jest filtrem deterministycznym, nie osobnym LLM.
Bez lokalnego MCP wykonaj osobną rolę Rzecznika i self-evaluation A-K w ChatGPT, raportując brak zewnętrznej weryfikacji. PASS narzędzia oznacza tylko walidację struktury, nie prawdziwości faktów.
